### Slug Generation
```typescript
function generateSlug(text: string): string {
  return text
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9\s-]/g, '')
    .replace(/\s+/g, '-')
    .replace(/-+/g, '-')
    .replace(/^-+|-+$/g, '');
}

// Examples:
// "Cara Membuat Website" → "cara-membuat-website"
// "Apa itu SEO?" → "apa-itu-seo"
// "Tips & Tricks!!!" → "tips-tricks"
```

## How It Works

### 1. User Selects Image
```
Click "Gambar Cover"
    ↓
File picker opens
    ↓
Select image file
    ↓
Preview displays
```

### 2. User Publishes Article
```
Click "Publikasi"
    ↓
[PARALLEL]
├─ Create draft (if new)
├─ Upload image to R2
└─ Get public URL
    ↓
PATCH article with featured_image_url
    ↓
Success! Article published
```

### 3. Slug Auto-Generation
```
Type title
    ↓
generateSlug() runs
    ↓
Slug field updated
    ↓
"✨ Auto" indicator shown
    ↓
User can edit slug → indicator disappears
```

## API Integration

### Upload URL Endpoint
```
GET /api/cms/articles/upload-url
Query: ?objectKey=articles/{id}/cover-{ts}-{name}&contentType=image/jpeg

Response:
{
  "objectKey": "articles/{id}/cover-...",
  "uploadUrl": "https://s3.../...",
  "publicUrl": "https://cdn.example.com/..."
}
```

### Article Update Endpoint
```
PATCH /api/cms/articles/{articleId}
{
  "title": "...",
  "slug": "...",
  "excerpt": "...",
  "content": "...",
  "featured_image_url": "https://cdn.example.com/articles/{id}/cover-...",
  "status": "draft|published|archived"
}
```

## Save Flow

### With Cover Image
```
saveArticle() called
    ↓
Create draft (POST /api/cms/articles/draft) if needed
    ↓
Upload image to R2 (PUT to signed URL)
    ↓
Get public URL from upload
    ↓
PATCH article with featured_image_url
    ↓
Clear preview state
    ↓
Show success toast
```

### Without Cover Image
```
saveArticle() called
    ↓
Create draft if needed
    ↓
PATCH article (featured_image_url unchanged)
    ↓
Show success toast
```

## Troubleshooting

### Upload Fails
1. Check R2 credentials
2. Verify bucket exists
3. Check CORS policy
4. Verify R2_PUBLIC_BASE_URL is correct

### Signed URL Fails
1. Check `/api/cms/articles/upload-url` endpoint
2. Verify server can reach R2
3. Check URL expiry (default 300s)

### Slug Doesn't Generate
1. Check `slugAutoGeneratedRef.current = true`
2. Verify title is entered
3. Check for JS errors in console

### Image Doesn't Display
1. Verify featured_image_url in database
2. Check R2 public URL is correct
3. Verify CORS allows GET from origin

## Performance Tips

### File Size
- 100KB image: ~1-2 seconds upload
- 1MB image: ~10-15 seconds upload
- 10MB image: ~1-2 minutes upload

### Optimization
- Compress images before upload
- Use modern formats (WebP > JPEG)
- Avoid uploading during peak hours
