### 3. Parallel Upload to R2

**Process:**
1. User selects image file
2. Real-time preview displayed
3. On save (draft/publish):
   - Create draft article (if new)
   - **Upload image to R2** (parallel)
   - Update article with image URL
4. Image stored in R2, URL saved to database
5. No files stored on app server (memory efficient)

**Object Key Pattern:**
```
articles/{articleId}/cover-{timestamp}-{sanitized-filename}
Example: articles/550e8400.../cover-1705779200000-my-cover.jpg
```

### 4. Auto-Generated Slug from Title

**Regex Pattern Applied:**
```javascript
text
  .toLowerCase()                    // hello world
  .trim()                           // hello world
  .replace(/[^a-z0-9\s-]/g, '')   // remove special chars
  .replace(/\s+/g, '-')             // spaces to dashes
  .replace(/-+/g, '-')              // collapse dashes
  .replace(/^-+|-+$/g, '')          // trim dashes
```

**Examples:**
```
"Cara Membuat Website" → "cara-membuat-website"
"Apa itu SEO?" → "apa-itu-seo"
"Tips & Tricks 2026" → "tips-tricks-2026"
```

**Behavior:**
- Auto-generates when title changes
- Shows "✨ Auto" indicator in slug field
- User can edit slug to override
- Auto-generation stops after manual edit
- Fully editable field (not read-only)

### New Functions Added

#### 1. `uploadCoverImageToR2(file: File, articleId: string): Promise<string>`
Uploads image file to Cloudflare R2:
- Generates unique object key with timestamp
- Gets signed upload URL from backend
- Performs direct PUT to R2 (browser → R2)
- Returns public URL for storage in database
- Throws error if upload fails

#### 2. `handleCoverImageSelect(e: React.ChangeEvent<HTMLInputElement>): void`
Handles file selection:
- Validates file size (max 10MB)
- Creates preview using FileReader
- Stores file in state
- Marks form as dirty
- Resets input for re-selection

#### 3. `handleRemoveCoverImage(): void`
Removes selected image:
- Clears file and preview
- Preserves previously uploaded URL
- Marks form as dirty

## User Experience Flow

### Creating Article with Cover Image

1. Navigate to `/admin/articles/compose`
2. Enter title → Slug auto-generates
3. Click "Gambar Cover" → File picker opens
4. Select image → Preview appears
5. Enter excerpt and content
6. Click "Publikasi"
   - Footer shows "Mengunggah gambar..."
   - Image uploads to R2 (parallel with save)
   - Article saved with image URL
   - Toast: "Artikel dipublikasi"

### Editing Article and Replacing Cover

1. Click "Edit" on article card
2. Composer loads with existing data and image
3. Click "Ganti" on preview
4. Select new image → Preview updates
5. Click "Publikasi"
   - New image uploads, replacing old one
   - Database updated with new URL

### Remove Cover Image

1. Click "Hapus" button on image preview
2. Preview cleared
3. Click "Publikasi" → featured_image_url removed

## Security Considerations

### File Upload Security
1. **Client-side validation** — File type and size
2. **Signed URLs** — Backend generates 5-minute expiry
3. **R2 bucket** — Validates signature before accepting PUT
4. **Object keys** — Timestamp + sanitized name prevents collisions
5. **CORS policy** — Restricts cross-origin uploads

### Authorization
- User must be authenticated before saving
- Article ownership validated on server
- Unsigned upload attempts rejected by R2
